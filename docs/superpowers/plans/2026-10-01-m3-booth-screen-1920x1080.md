# M3 — The Booth Screen at 1920×1080 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The booth screen laid out and proven at the full **1920×1080** canvas at **100 / 125 / 150 / 200 %** DPI, with an attract mode for the idle screen, a presenter drawer that does not disturb the layout, and a **2–3 m readability review** — plus the committed screenshot M1 could not produce and the experiment that settles whether the input-acknowledgement gate is merely insensitive or actively misleading.

**Architecture:** The M2 layout is already correct and honest; this milestone changes what it *looks like at size* and proves it **offscreen at four scale factors**, because the demo machine's desktop is 2293×960 and a 1920×1080 canvas cannot be shown on it. `tools/capture_ui.py` renders the real scene graph offscreen at a requested geometry and scale, which is what makes the DPI gate testable at all.

**Tech Stack:** Python 3.12.10, `openvino==2026.4.0`, `PySide6==6.11.2`, `numpy==2.5.3`, `opencv-python==5.0.0.93`, `psutil==7.2.2`. Tests use stdlib `unittest`; `pytest` is deliberately not added.

**Spec:** `docs/superpowers/specs/2026-10-01-intel-edge-ai-roadshow-design.md` and `Intel-Edge-AI-Roadshow-Specification.md` §7 (staleness), §8 (UI / attract mode / presenter), §10 M3.

## Global Constraints

- Pinned exactly; stdlib `unittest`; no `pytest`; no new dependency.
- Explicit `compile_model(device)` targets only. **No `AUTO`, `HETERO`, `MULTI`.**
- `EXECUTION_DEVICES`, re-read **after** the first inference from the request's own compiled model, is the only proof of placement. It is inconsistent: NPU bare string `'NPU'`, CPU `['CPU']`, GPU `['GPU.0']`. Always `is_device` / `normalise_execution_devices`.
- **Unavailable is `null`, never `0`.** Every optional metric renders through the bridge's notified properties; the CPU card must never wear the accelerator's "Utilization unavailable" wording.
- **GPU/NPU utilisation is unavailable** in the runtime path and a machine-wide peak is **not attributable to this process**. Cards show inference activity. Never a number.
- Static shapes: batch 1, 640×640, pad **114**, boxes **`cx,cy,w,h`**, `has_embedded_nms=False`.
- The retail event is **people-in-zone presence**, 2 per clip — **not** a people count, **not** a dwell measurement. `app/engine/retail_config.py`'s `scope_note` is the exact wording to reuse.
- **Frame age and inference cost are separate claims and are never merged.** At 1920×1080 the frame-age number must be legible at a glance *because* it is frequently 11-14 s.
- **No QML binding to a Slot that reads mutable state.** The standing guard exists, is line-oriented by design, has a two-entry allow-list that must be maintained, and caught a dead `?` panel at the booth in M1. **A `Repeater` delegate is invisible to `findChild`/`children()`**, and **`Math.max` passes `NaN` through** — both have already produced passing tests over empty results.
- Layout tokens in `app/theme.py`. No metric values or magic numbers in QML.
- Nothing in `app/` imports from `tools/`.
- `time.monotonic()` has ~16 ms resolution here; use `perf_counter` for elapsed time. A published timing figure needs repeats, stated as a range.

**M2 facts this milestone builds on, all measured:** 1210 tests green, exit 0; suite 359.1–359.9 s; `verify_sources` 6 PASS/0 FAIL; `preflight` 16 PASS/2 WARN/0 FAIL (Limited); `--selftest` PASS. Three camera pipelines each with their own clip, decode thread, `Tracker` and event machine, each tile serving its own stream (`image://frames/{A,B,C}`). Placement confirmed CPU→`CPU`, GPU→`GPU.0`, NPU→`NPU`, 50/50 transitions with `placement_pids_matched` 50/50. **Frame staleness is already on screen per stream**: `STALE - this picture is 10.8 s old; the limit is 2 s`, window `256 analysed frames`, backlog and analysis rate. A failed stream claims **no device** (`device: failed - no device is running`, `confirmed: []`). Presenter-driven selection observed with badges in order `pending - CPU not yet confirmed` → `pending - GPU not yet confirmed` → `device: GPU.0`.

**The machine is measurably slower than earlier in M2** (CPU p50 22.4–22.8 ms vs 21.0–21.2 ms logged; frame age 14.3–14.7 s vs 10.7–11.3 s), **cause not established.** Report ranges; prefer the committed figure over the best observed; do not explain a drift you have not diagnosed.

## Review Focus

1. **A DPI claim that was never rendered at that DPI.** The gate is a real render at each scale factor, not a font-size calculation and not a `QT_SCALE_FACTOR` variable read back.
2. **A screenshot that looks right and is wrong.** M2's caption read `Camera B · -1` with a correct badge and a correct picture above it. **A rendered string can be wrong while everything around it is right** — read the strings, do not trust the PNG.
3. **Text that fits at 100 % and clips at 150 %.** The busiest state is not three healthy streams; it is **three streams with 11-14 s frame ages and long error reasons on screen at once.**
4. **Attract mode leaking state.** It must not fabricate a reading, must not show a stale number as live, and must exit to exactly the state it interrupted.
5. **The presenter drawer moving the layout under it.** Opening a drawer must not shift the hero, the badges, or the staleness line — a presenter opening a drawer mid-demo must not be able to break the picture.

## M3 exit criteria

1. The screen renders at 1920×1080 with **no overflow and nothing pushed outside the canvas** at 100, 125, 150 and 200 %.
2. Every number a passer-by must read is legible at **2-3 m**, or the failure is documented.
3. A committed screenshot exists at each scale factor, with its strings read out of the scene graph.
4. Attract mode shows **no number it cannot date**, and restores the interrupted state exactly.
5. The presenter drawer moves nothing, and states the retail scope note verbatim.
6. The input-ack gate's blindness to inference backlog is **demonstrated**, not asserted.
